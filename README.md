# Block3D AI

Browserbasierte 3D-Modell-Demo für Roblox-Creator.

## Funktionen
- Dunkles, responsives Design mit eisblauen Akzenten
- Interaktive 3D-Vorschau mit Drehen und Zoomen
- Beispielmodelle: Objekt, Charakter, Fahrzeug und Gebäude
- OBJ- und STL-Export

## Hinweis zur KI
Diese erste Version ist ein funktionsfähiger 3D-Demo-Generator aus Grundformen. Sie erzeugt noch keine komplexen Modelle mit einer echten KI. Dafür wird später ein serverseitiges KI-Backend benötigt. API-Schlüssel gehören niemals in den Browser-Code.

## Online stellen
1. Öffne https://vercel.com und melde dich an.
2. Wähle **Add New → Project** und importiere `king67324/Block3D-AI`.
3. Framework Preset: **Other**. Build Command und Output Directory leer lassen.
4. Klicke **Deploy**. Vercel zeigt danach deine öffentliche Website-Adresse an.
